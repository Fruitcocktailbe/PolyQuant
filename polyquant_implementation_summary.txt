# PolyQuant Mathematical Framework Implementation

## Summary
Implemented the core mathematical framework from Kroer et al. 2016 for detecting and extracting arbitrage in LMSR-based prediction markets.

## Components Implemented

### 1. Data Module (`data/`)
New module providing:
- `market_models.py` - Pydantic models for Market, OrderBook, ProposedTrade, ArbitrageOpportunity
- `polymarket_client.py` - API client for Polymarket CLOB

---

### 2. Barrier Frank-Wolfe (`solver/bregman.py`)
Complete rewrite of the module.

**Key Class: `BarrierFrankWolfe`**

Solves the LMSR gradient explosion problem by optimizing over a contracted polytope:
```
M' = (1-ε)M + εu
```

**Adaptive Epsilon Rule:**
```
ε_t = min(g(μ_t)/(-4*g_u), ε_{t-1}/2)
```

**Profit Guarantee (Proposition 4.1):**
```
Guaranteed Profit ≥ D(μ̂||θ) - g(μ̂)
```

**α-Extraction Stopping:**
```
Stop when: g(μ_t) ≤ (1-α) × D(μ_t||θ)
```
With α=0.9, we capture 90% of available arbitrage.

---

### 3. InitFW Algorithm (`solver/scip_solver.py`)
New implementation added to SCIP solver.

**Function: `init_frank_wolfe()`**

Implements Algorithm 3 from the paper:
1. For each security, probe x_i=0 and x_i=1 feasibility
2. If only one value feasible → security is logically settled
3. If both feasible → add vertices to Z₀
4. Compute interior point u = average(vertices)

**Returns `InitFWResult`:**
- `vertices` - Extreme points for Frank-Wolfe
- `interior_point` - For Barrier FW contraction
- `logically_settled` - Securities with forced values
